# 🏨 Hotel AGHM

Hotel management system developed in **C/C++** as one of the first projects of the **Computer Science** undergraduate program.

The system allows users to manage room reservations and occupancy, as well as access guest information and monitor the hotel's occupancy rates.

## 📋 Features

- 🛎️ **Guest check-in**
- 🚪 **Guest check-out**
- 📅 **Room reservations**
- ❌ **Reservation cancellation**
- 🔎 **Room status lookup**
- 📊 **Reservation and occupancy rate calculation**
- 🗺️ **General room map**
- 👤 **Guest data registration and lookup**
- 🔐 **CPF validation** for reservation check-in

The hotel is represented by a structure of **20 floors**, with **14 rooms per floor**, totaling **280 rooms**.

## 🗺️ Room Status

The hotel map uses three states to represent the rooms:

| Symbol | Status |
|:------:|--------|
| `.` | Available |
| `r` | Reserved |
| `o` | Occupied |

## 🛠️ Technologies

- **C**
- **C++**
- `struct`
- Matrices
- Functions
- Control structures
- Input and output handling

## 📚 Objective

The project was developed to apply fundamental programming and data structure concepts in the construction of a functional hotel management system.

The main concepts used include the creation and manipulation of structures to represent guests and their addresses, as well as the use of matrices to represent the hotel's rooms.
